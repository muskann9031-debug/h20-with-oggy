# H2O with Oggy 💧🎮

**An interactive water-sustainability game | Smart India Hackathon team project**

[**Play the deployed game**](https://h20-with-oggy.vercel.app/) · [**Original team repository**](https://github.com/codewithakshyaaa/h20-with-oggy)

## Overview

H2O with Oggy is a team-built, Oggy-inspired interactive web game developed for a Smart India Hackathon project. It explores how playful, character-led experiences can engage users with water conservation and sustainable water management, aligning with the themes of **UN Sustainable Development Goal 6: Clean Water and Sanitation**.

The project brings together web-based interaction, game logic, and visual interface design to make sustainability education more approachable.

## Highlights

- **Interactive, game-oriented experience** built around a water-sustainability theme.
- **Character-inspired presentation** influenced by Oggy and the Cockroaches.
- **Custom game logic and UI design**, developed collaboratively by the team.
- **Web deployment** so the project can be accessed without local installation.

## Run Locally

**Prerequisites:** Node.js and a compatible package manager.

```bash
git clone https://github.com/codewithakshyaaa/h20-with-oggy.git
cd h20-with-oggy
npm install
npm run dev
```

Open the local URL shown in your terminal. The repository's Vite development script uses port `3000` by default.

If environment variables are required for a particular feature, refer to `.env.example` and provide your own values in a local `.env` file. Never commit real credentials.
